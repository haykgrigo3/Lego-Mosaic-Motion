# Projects Folder

Drop exported project bundles here so they are easy to browse in GitHub.

Recommended pattern:

- one folder per project
- keep the exported file names intact when possible
- include `project.json` at minimum
- include `piece-list.json`, `piece-list.csv`, `README.txt`, and optional `frames/` and `renders/` when available

The bundled `demo-project/` folder is a tiny hand-made example that works with the standalone viewer.
