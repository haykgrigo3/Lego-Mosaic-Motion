LEGO Mosaic Motion Studio Export

Project name: demo-project
Source file: demo-source.mp4
Frame count: 4
Output grid: 4 x 4
Render FPS: 2
Stud style: 1x1 square tiles
Palette: Demo Palette

Included files:
- project.json: full frame-by-frame project data for custom tools and Blender pipelines
- piece-list.json: summary piece counts for the whole sequence and every frame
- piece-list.csv: spreadsheet-friendly version of the piece counts
- README.txt: this guide

How to use the data:
1. Open standalone-projects/index.html and load project.json.
2. Scrub through frames to inspect the encoded animation.
3. Expand paletteRuns if you want a full per-cell color grid for custom scripts.
